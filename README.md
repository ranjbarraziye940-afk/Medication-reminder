# یادآور دارو (Medicine Reminder)

## ۱. معرفی پروژه
این پروژه یک برنامه یادآور مصرف دارو است که با زبان برنامه‌نویسی پایتون (Python) طراحی خواهد شد. هدف آن کمک به کاربران برای مدیریت داروهای مصرفی و یادآوری زمان مصرف داروها است.

## ۲. توضیحات پروژه
کاربران می‌توانند اطلاعات داروهای خود را ثبت کنند و برای زمان مصرف آن‌ها یادآور تنظیم کنند. این برنامه با هدف منظم‌تر کردن مصرف داروها و کاهش احتمال فراموش کردن زمان مصرف طراحی می‌شود.

## ۳. امکانات پروژه
- ثبت نام دارو و اطلاعات مربوط به آن
- تعیین مقدار و زمان مصرف دارو
- تنظیم یادآور برای زمان مصرف دارو
- مشاهده برنامه روزانه مصرف داروها
- مدیریت فهرست داروهای ثبت‌شده

## ۴. فناوری‌های مورد استفاده
- **زبان برنامه‌نویسی:** Python
- **محیط توسعه:** Visual Studio Code یا PyCharm
- **مدیریت نسخه:** Git و GitHub
- **کتابخانه‌ها:** در مراحل بعدی مشخص خواهند شد
