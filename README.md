# Medication-reminder
نام محصول: یادآور دارو 
این پروژه یک برنامه یادآور دارو است. که به کاربران این امکان را می‌دهد تا برای مصرف به موقع داروهای خود از یادآورهای این برنامه استفاده کنند.
مسئله:
کاربران با ثبت اطلاعات داروهای خود می‌توانند زمان مصرف آنها را با یادآور تنظیم کنند هدف این برنامه منظم مصرف کردن داروها و عدم فراموشی زمان مصرف دارو است.
ویژگی‌ها:
ثبت اسم دارو و توضیحات آن
تعیین مقدار و زمان مصرف
مشاهده برنامه روزانه مصرف دارو
مدیریت فهرست داروها
فناوری اولیه:
زبان برنامه نویسی: پایتون
محیط توسعه: VS Code
مدیریت نسخه: Git, GitHub
